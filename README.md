# Dock — мобильное приложение для перевозки негабаритных грузов

Версия **1.0** (финальная сдача). Заказчик публикует заявку с габаритами груза, водители со спецтехникой
видят только подходящие их транспорту заявки и предлагают цену, заказчик может ответить встречной ценой, выбирает
исполнителя и оплачивает (безопасная сделка), водитель ведёт рейс с обязательной фотофиксацией, стороны созваниваются
или пишут в мессенджер, получают уведомления о каждом шаге и оставляют отзывы. Если что-то пошло не так, любая
сторона открывает спор, и администратор решает, кому достанутся замороженные деньги.

Система из трёх частей:

```
Мобильное приложение (Expo / React Native)  ──HTTPS + JWT──▶  Dock API v1 (Node.js, Fastify)  ──ORM──▶  PostgreSQL
  iOS · Android · Web                                          /api/v1/…, Swagger /docs             в Docker
```

| Часть | Папка | Стек |
|---|---|---|
| Клиент | `src/` | TypeScript, React Native 0.88, Expo SDK 58, Expo Router, MVVM; шрифт Onest (`@expo-google-fonts/onest`) |
| Сервер API | `server/src/` | TypeScript, Fastify 5, MikroORM 7 (ORM), zod (схемы), bcrypt, JWT, Swagger |
| База данных | `server/src/database/migrations/`, `docker-compose.yml` | PostgreSQL 17 в Docker: 11 таблиц, 5 миграций |
| Тесты | `server/tests/` | `node:test`, 48 автотестов API на реальном PostgreSQL |

Документация API (Swagger) открывается на работающем сервере: <http://localhost:8000/docs>.

## Быстрый запуск

Нужны **Node.js 22.17+** и **Docker Desktop** (запущенный). Команды выполняются в папке проекта.

**Один раз** — установить всё (приложение и сервер; заодно создаётся `server/.env` со случайными секретами):

```bash
npm install
```

**Каждый раз:**

```bash
npm run dev
```

Команда сама поднимет PostgreSQL в Docker (`docker-compose.yml`, данные хранятся в томе `dock-pg`), применит
миграции, при пустой базе зальёт демо-данные, запустит сервер API и Expo. Дальше как
обычно: QR-код для Expo Go (телефон в той же Wi-Fi сети) или клавиша **w** — браузер. **Ctrl+C** останавливает всё.
Журнал сервера — `server/logs/dev.log`, документация API — <http://localhost:8000/docs>.

Демо-данные создаются один раз — в пустой базе — и дальше хранятся в Docker между запусками. Если во время показа
сменить пароль демо-пользователя, выдать ему временный пароль или заблокировать его, так и останется. `npm run dev`
при старте проверяет демо-учётки и, если они уже не совпадают с таблицей, пишет, какие именно. Вернуть всё как
в таблице — `npm run db:reset` (все данные в базе заменятся демо-данными).

## Команды по отдельности

В папке `server`:

| Команда | Что делает |
|---|---|
| `npm run db:migrate` / `npm run db:migrate:down` / `npm run db:status` | применить / откатить / показать миграции |
| `npm run db:seed -- --fresh` | пересоздать демо-данные |
| `npm run dev` | только сервер, журнал запросов в консоли (`DB_DEBUG=true` в `.env` — ещё и SQL) |
| `npm test` | 48 автотестов API (нужен запущенный PostgreSQL из Docker; отдельная база `dock_test` создаётся и пересоздаётся миграциями сама) |

В корне: `npm start` — только приложение, `npm run test:server` — автотесты API, `npm run db:reset` — вернуть демо-данные,
`npm run typecheck`, `npm run lint`.

База в Docker: `docker compose up -d` / `docker compose stop` — запустить / остановить; `docker compose down -v` —
удалить вместе с данными (следующий `npm run dev` развернёт её заново миграциями и демо-данными).
Выгрузка базы в файл `dock_dump.sql` — `npm run db:dump`; загрузить её обратно (текущие данные заменятся) —
`npm run db:restore`.

Приложение само находит сервер на порту 8000 того же компьютера, где запущен Expo. Другой адрес задаётся в `.env`
в корне: `EXPO_PUBLIC_API_URL=http://192.168.1.10:8000`.

## Если что-то не запускается

| Сообщение / симптом | Что сделать |
|---|---|
| «PostgreSQL не запустился» | Открыть Docker Desktop, дождаться статуса *Running* и повторить `npm run dev` |
| Порт 5432 уже занят | Остановить локально установленный PostgreSQL или поменять порт в `docker-compose.yml` (`"5433:5432"`) и в `DATABASE_URL` в `server/.env` |
| Порт 8000 уже занят | Закрыть программу на этом порту (часто — предыдущий запуск сервера) |
| «Неверный email или пароль» у демо-пользователя | Данные в базе изменились (см. предупреждение при `npm run dev`) — `npm run db:reset` |
| При запуске «⚠ Это не локальная база из Docker» | В `server/.env` осталась строка от старой версии: `DATABASE_URL=postgres://postgres:postgres@localhost:5432/dock` |
| Expo Go: «project is incompatible with this version of Expo Go» | Обновить Expo Go из App Store / Google Play (проект на Expo SDK 58) |
| QR-код открывается, но приложение не видит сервер | Телефон и компьютер в одной Wi-Fi сети (не гостевой); брандмауэр разрешает входящие на порты 8081 и 8000; при необходимости задать `EXPO_PUBLIC_API_URL` (см. выше) |
| Нет файла `server/.env` | `npm --prefix server run env:init` |
| Нужна полностью чистая база | `docker compose down -v`, затем `npm run dev` |

## Структура репозитория

```
Dock-app/
├── src/                    мобильное приложение (MVVM)
│   ├── app/                маршруты Expo Router (тонкие файлы)
│   ├── views/              экраны и компоненты
│   ├── viewmodels/         состояние экранов, проверка форм
│   ├── services/           сценарии (UC) поверх репозиториев
│   ├── repositories/       HTTP-запросы к API
│   ├── models/             DTO, типы API, схемы форм, доменные правила
│   └── core/               HTTP-клиент, хранение токена, конфигурация
├── server/
│   ├── src/
│   │   ├── routers/        HTTP: маршруты /api/v1/…, схемы запросов/ответов
│   │   ├── services/       бизнес-правила и проверка прав
│   │   ├── repositories/   доступ к данным через ORM
│   │   ├── models/         ORM-модели (сущности)
│   │   ├── schemas/        схемы API (zod — аналог Pydantic)
│   │   ├── database/       подключение ORM, миграции, seed
│   │   ├── core/           конфигурация, безопасность, ошибки
│   │   ├── dependencies.ts Session на запрос, текущий пользователь, роли
│   │   ├── app.ts          сборка приложения (Swagger, CORS, обработка ошибок)
│   │   └── main.ts         запуск
│   └── tests/              автотесты API
├── docs/                   документация для защиты
├── scripts/dev.mjs         запуск всего проекта одной командой (npm run dev)
└── docker-compose.yml      PostgreSQL 17 в Docker
```

| UC-18 | Подтвердить приёмку | Экран рейса (после фото выгрузки) |

| UC-22 | Заблокировать пользователя | Администратор → карточка пользователя |

Не реализовано: карта и GPS (UC-05, UC-16 — местоположение; статус рейса показывается), платёжный шлюз (UC-12–14
работают в демо-режиме), спецразрешения (UC-23), push-уведомления на телефон (уведомления
внутри приложения есть), встроенный чат (вместо него — звонок и мессенджеры).
